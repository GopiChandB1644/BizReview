# BizReview - Business Review Mobile App

A Flutter mobile application for reviewing and rating businesses with Firebase backend.

## Features

✅ **Authentication**
- Email/Password login and signup
- Google Sign-In integration
- User profile management

✅ **Business Management**
- Browse business listings
- Add new businesses with images
- View business details with tabs (Description & Reviews)
- Business categories and ratings

✅ **Review System**
- 5-star rating system
- Add reviews with comments
- View all reviews for a business
- View user's own reviews

✅ **Profile Management**
- Upload profile picture
- Edit username
- View review history

## Tech Stack

- **Framework:** Flutter
- **State Management:** Provider
- **Backend:** Firebase (Authentication, Firestore)
- **Authentication:** Firebase Auth + Google Sign-In
- **Database:** Cloud Firestore
- **Image Storage:** Base64 encoding in Firestore

## Setup Instructions

### Prerequisites
- Flutter SDK (3.8.1 or higher)
- Firebase account
- Android Studio / Xcode
